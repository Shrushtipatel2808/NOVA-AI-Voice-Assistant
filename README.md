
# NOVA AI - Python Voice Assistant 🤖

NOVA is a beginner-friendly Python voice assistant
that interacts with users through voice responses.

## Features
- Voice greetings
- Current date and time
- Basic calculations
- Text-to-speech responses
- Interactive chat loop
- Exit command

## Technologies Used
- Python
- pyttsx3
- datetime

## Installation

pip install -r requirements.txt

## Run the Project

python nova.py
