
# NOVA AI - Python Voice Assistant 🤖

NOVA is a beginner-friendly Python voice assistant that interacts with users through voice responses using Text-to-Speech.

## Features

- Greeting and basic conversations
- Tells current date
- Tells current time
- Performs basic mathematical calculations
- Speaks responses using pyttsx3
- Continuous conversation using a while loop
- Exit command to stop the assistant

## Technologies Used

- Python
- pyttsx3
- datetime

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python main.py
```

## Example Commands

- Hello
- How are you?
- What is your name?
- Tell me the time
- Tell me the date
- Calculate 10 + 20
- Exit
